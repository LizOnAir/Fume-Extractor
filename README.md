# 2 in 1 Fume extractor
A 3d print fume extractor, to stop solder fumes from flooding my face when I'm soldering.
When you feel hot, simply detach the fan and turn around to use as a mini fan.

## Features:
- magnetic casing
- battery powered
- portable
